# Electric Vehicle Market Performance & Insights

This self-contained dashboard is calculated from the two provided CSVs (200,000 training rows and 100,000 testing rows). It has no external JavaScript or chart-library dependency.

## Preview
Open `index.html` in a modern browser.

## Publish a public demo URL
1. Create a **public** GitHub repository named `ev-market-performance-demo`.
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose branch `main` and folder `/(root)`, then Save.
4. Wait for deployment and use the URL shown by GitHub Pages, usually `https://YOUR-USERNAME.github.io/ev-market-performance-demo/`.

The CSV files do not need to be uploaded because summary data is embedded in the HTML.
